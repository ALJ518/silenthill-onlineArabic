# silenthill-online-arabic
نسخه من مشروع silenthill-online مناسبه خصيصا لتعريب الحلم المتجدد
تنبيه :
هذا المشروع لا يحتوي على ملفات rom او مود تعريب هذا المشروع فقط مخصص لتعريب الحلم المتجدد واصلاح اماكن الحروف ليتناسب مع تعريب الحلم المتجدد

خطوات التشغيل :
1 : ضع روم اللعبه في ملف gamedata ملفي bin و cue 
2 : تشغيل اللعبه عبر SilentHillPC.exe 
وتعديل اعدادات العبه عبر SilentHillPC_Launcher.exe 
كيفيه تشغيل الاون لاين وكل شي مشروح في المشروع الاصلي 
https://github.com/SlickAmogus/silenthill-online
التعريب من قبل : الحلم المتجدد
https://etrdream.com/game/silent-hill/
